### Tsuki: 一款仿webchat的AI聊天应用 ###
旨在提供更真实的AI陪伴体验

## 特点 ##
1. 预人设机制: 搜索添加好友时请求一次模型, 提供人设标签与头像, AI选择后渲染到界面, 因此所有的头像和人设均是AI自主选择.
2. 朋友圈机制(开发中): AI可跟据会话内容, 自主决定发送朋友圈动态, 您和AI均可点赞与评论, 以及在聊天中记忆朋友圈内容.
3. 支持文件与emoji发送.
4. 消息通知(开发中): 一段时间不理睬的话会主动向您发消息, 并发送系统提示, 次数限制, 不会导致骚扰.
